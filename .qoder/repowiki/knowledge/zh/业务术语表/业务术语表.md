### 砺算 7G100
- 定义：砺算科技（Lisuan Technology，PCI Vendor ID 4c54）生产的 GPU 型号，本仓库中具体设备 ID 为 `4c54:5006`，属于 G100 家族。该显卡在本项目中使用官方提供的 `lisuangpu-dkms` 驱动进行 DRM/KMS 显示输出。
- 别名：G100、LT 4c54:5006

### DKMS 构建变量名不匹配
- 定义：砺算驱动 Makefile 使用 `KERNEL_VERSION`（默认取 `uname -r` 当前运行内核）作为目标内核标识，但 `dkms.conf` 通过 `KERNELVER` 传递目标内核——两个变量名不一致导致 DKMS 忽略目标内核，始终按构建时运行的内核编译，产生 vermagic 错配的模块。
- 别名：KERNEL_VERSION vs KERNELVER、DKMS 变量名 Bug

### vermagic 错配
- 定义：内核模块的 `vermagic` 字段（由 `modinfo` 查看）包含编译时的内核版本号，加载时必须与运行内核一致。本项目中因 DKMS 用 6.8 头文件编译却装入 7.0 目录，导致 `vermagic: 6.8.0-31-generic` 与运行内核 `7.0.0-28-generic` 不匹配，模块被内核拒绝加载。
- 别名：vermagic mismatch、模块版本魔数不匹配

### 信创平台
- 定义：指国产信息技术应用创新平台，本项目中特指基于海光（Hygon）x86 CPU 的国产化服务器/工作站环境，砺算 GPU 在此类平台上通过 DKMS 方式安装和更新驱动。
- 别名：国产化平台、Hygon 平台

### 源码重编优先于反编译
- 定义：砺算驱动的闭源部分仅为预编译对象归档（`lisuan_proprietary.o.hex`），对外仅依赖极少量稳定内核符号（`__fentry__`、`sscanf`），其余接口均来自可重新编译的开源胶水层。因此遇到内核 API 变更时，优先通过修改源码并重新编译解决，而非对闭源二进制进行反编译。
- 别名：闭源 blob 分析、recompile over decompile
