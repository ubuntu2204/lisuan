模块以 lisuan_drv.c 为 DRM 驱动入口，通过 drm_driver/drm_ioctl_desc 注册 IOCTL 并挂载子子系统：lisuan_device.c 负责 PCI 设备探测、BAR 映射、文件打开/关闭生命周期；lisuan_gem.c 基于 TTM/DMA-BUF 实现 GEM 对象分配、页表管理与 CPU/GPU 一致性；lisuan_vm.c / lisuan_vm_cpu.c / lisuan_vm_gpu.c 分别处理 CPU 侧与 GPU 侧页表更新；lisuan_ring.c + gf_ringbuffer.c 为各引擎（gfx/gce/vem/dec）维护命令环缓冲；gf_job.c 将上层提交封装为 sched_job 并注入命令流；lisuan_sched_main.c / lisuan_sched_entity.c / lisuan_sched_fence.c 实现自定义调度器实体与 fence 同步；gf_irq.c 处理 VSync/HPD/DP 等中断；lisuan_fb.c 提供 fbdev 兼容层；lisuan_mailbox.c / lisuan_p2pdma.c / lisuan_sync.c / lisuan_trace_points.c / lisuan_procid.c 提供辅助通道；gf_os_interface.c 统一封装 MMIO 读写、内存分配与打印，屏蔽 FAKE_CHIP/端序差异；log_control.c 通过 procfs 暴露日志开关。依赖方向自上而下：drm/ioctl → device/gem/vm/ring → job/sched → irq/hw，gf_os_interface 作为底层 HAL 被所有层调用。
