- 所有公开函数以 gf_ 前缀（通用层）或 lisuan_ 前缀（DRM 层）命名，形成清晰的命名空间隔离。
- 通过 DRM_VERSION_CODE 与 LINUX_VERSION_CODE 宏进行内核版本分支，对 struct file_operations/proc_ops、DMA_BUF 命名空间导入等进行条件编译适配。
- 模块级配置参数统一使用 module_param + MODULE_PARM_DESC 声明，并在运行时通过 sysfs/module 参数动态调整行为。
- 硬件访问统一走 gf_read_mmio*/gf_write_mmio* 与 gf_malloc/gf_free/gf_calloc 等 OS 抽象接口，FAKE_CHIP 下直接返回零值以支持无硬件测试。
- 调试输出通过 gf_printk/gf_debug/gf_info/gf_error 等分级打印，受全局 print_level 与 lisuan_debug 位掩码联合控制。
- 每个 .c 文件顶部保留统一的版权头（@Copyright Lisuan Tech / Dual MIT/GPLv2），模块元信息集中在 lisuan_drv.c 末尾的 MODULE_* 宏中。
