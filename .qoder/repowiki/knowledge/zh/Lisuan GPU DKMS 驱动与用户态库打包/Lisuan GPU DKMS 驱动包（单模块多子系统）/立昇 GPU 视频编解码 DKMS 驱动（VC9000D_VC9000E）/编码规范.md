- 所有 C 文件顶部包含双许可证声明块（MIT/GPL 或 BSD/GPL），并保留 SPDX-License-Identifier 标记。
- 硬件寄存器访问统一通过 `vcmdswhwregisters.h` 中的 `vcmd_read_reg`/`vcmd_write_reg` 以及 `vcmd_set_register_mirror_value`/`vcmd_get_register_mirror_value` 进行，避免直接 I/O 操作。
- ioctl 函数命名遵循 `xx_HANTRODEC_IO*` / `xx_HANTRO_VCMD_IO*` / `xx_HANTRO_IOCH_*` 前缀约定，参数统一为 `(drm_device *, void *data, struct drm_file *file_priv)` 三件套。
- 跨平台兼容性通过 `#ifdef __linux__` / `#ifdef __FREERTOS__` / `#ifdef __cplusplus` 条件编译隔离，公共 API 使用 `extern "C"` 包裹。
- 数据结构定义集中放在同名 `.h` 文件中，`.c` 文件仅包含对应头文件并通过 `gf_debug` 输出调试信息，不使用 `printk`。
