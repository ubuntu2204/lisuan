该模块是纯 C/C++ 头文件集合，作为 UMD（用户态驱动）与 KMD（内核态 DRM 驱动）之间的 ABI 契约层，按职责划分为三类：
- 核心共享接口：`umd_kmd_share.h` 定义双端共用的 allocation、resource、escape 操作等数据结构；`lisuan_drm.h` 基于这些结构通过 `DRM_IOWR` 宏批量声明所有 DRM ioctl 命令编号及参数类型，并包含 video 子模块头文件。
- 平台/硬件抽象：`reg_base.h` 以 C++ 命名空间暴露 CPIA/MHB/MMU/PMU 的 MMIO 基址与掩码；`driver_settings.h` 提供运行时可配置项结构体。
- 视频编解码子系统：`video/` 目录内 `hantrodec.h`、`vcx_driver.h`、`hantrovcmd.h`、`vc9000_common.h` 共同描述 Hantro/VeriSilicon 视频 IP 的核心描述、命令缓冲、交换参数等，被 `lisuan_drm.h` 统一引入。
- 仿真桥接：`rtsim_kmd_share.h` 面向 Windows RTsim 环境，通过函数指针表 `RsStubFunc` 将 Dxgk/内存/寄存器访问等 API 抽象为回调，实现跨平台仿真。
依赖方向单向收敛：video/* → lisuan_drm.h → umd_kmd_share.h；reg_base.h 独立被底层代码引用；rtsim_kmd_share.h 独立服务于仿真路径。
