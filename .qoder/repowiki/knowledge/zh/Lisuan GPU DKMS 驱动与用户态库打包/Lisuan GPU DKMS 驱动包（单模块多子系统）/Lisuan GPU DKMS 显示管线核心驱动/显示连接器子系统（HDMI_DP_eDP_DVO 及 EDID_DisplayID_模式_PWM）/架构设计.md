模块以 `disp_connector_t` 为核心数据结构，通过函数指针表 `disp_connector_func` 将通用连接器操作（detect、probe_edid_block、get_hpd_status、backlight_query/set、psr_query/set、irq_hpd_handle、get_i2c_status）分派给具体连接器实现，形成典型的虚表多态架构。

- 公共接口层：`disp_connector.c/.h` 提供 `disp_connector_sw_init/sw_deinit/probe_edid/get_i2c_status` 等统一入口，根据 `DISP_CONNECTOR_TYPE`（HDMI/DP/eDP/DVO）路由到对应子模块。
- 具体连接器实现：`disp_hdmi_connector.c/.h`、`disp_dp_connector.c/.h`、`disp_dvo_connector.c/.h` 各自填充 `disp_connector_func` 并实现本接口的 EDID 读取、HPD 检测、音频/PSR/背光等特性。
- 协议辅助层：`disp_dp_aux.c/.h` 封装 DisplayPort AUX/DDC 事务；`disp_edid.c/.h` 与 `disp_displayid.c/.h` 分别解析 EDID 1.x/2.0 及 DisplayID 扩展块。
- 模式与工具层：`disp_mode.c/.h` 提供 CVT/GTF 时序生成、模式匹配与验证；`disp_pwm.c/.h` 暴露背光 PWM 设置接口供 eDP 背光使用。
- 依赖方向：连接器实现 → 协议辅助（dp_aux/edid/displayid）→ 底层设备抽象（display.h/disp_device.h），上层不直接访问具体连接器细节。
