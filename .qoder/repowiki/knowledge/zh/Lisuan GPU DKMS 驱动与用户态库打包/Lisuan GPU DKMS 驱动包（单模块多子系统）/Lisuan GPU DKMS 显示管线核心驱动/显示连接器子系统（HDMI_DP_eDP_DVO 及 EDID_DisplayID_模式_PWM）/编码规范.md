- 所有连接器类型通过枚举 `DISP_CONNECTOR_TYPE` 标识，并在初始化时按类型分支调用对应的 `*_connector_sw_init/deinit`。
- 每个连接器文件均定义本地 `disp_print` 宏，统一通过 `disp_print_ex(DISP_PRINT_MASK_CONNECTOR_*)` 输出日志，并可选写入文件。
- 数据类型统一使用 `disp_u8_t`、`disp_s32_t`、`pdisp_void_t` 等前缀化 typedef，避免直接使用原生 C 类型。
- EDID/DisplayID 解析采用固定长度常量（如 `EDID_LENGTH=128`、`DISP_EDID_MAX_LENGTH=512`）配合循环重试机制读取多个 block。
- 功能扩展通过结构体中的位域标志（如 `disp_connector_t::flag.info.*`、`disp_dsc_caps_t::bits.*`）描述能力，而非单独参数。
