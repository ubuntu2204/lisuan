该目录采用「自动生成头文件 + 统一访问宏」的两层结构：
- 自动生成层：除 `disp_reg.h` 外，其余 `*_register.h` 均由工具生成（文件头部标注 `Generated Time` 与 `Do not modify it manually`），每个文件对应一个硬件模块，内部以 `Reg_<Name>_<Addr>` 联合体描述寄存器位域，并配套 `Register_<Block>_Mmio_<N>_Start` 基址宏与 `REG_<BLOCK>_START/END/LIMIT` 范围宏。
- 统一访问层：`disp_reg.h` 集中定义 `reg32_write_field_1..12` / `reg8_write_field_1..8` 及其对应的 read 系列宏，通过 `Expand(...)` 变参展开实现任意字段数目的读写；同时提供 `crtc_write_field`/`dp_write_field`/`dsc_write_field`/`sr_write_field`/`cr_write_field` 等按实例索引自动叠加 `pdd->reg_off.*` 偏移的封装宏，屏蔽不同模块的寄存器基址差异。
- 依赖方向：各 `*_register.h` 仅暴露类型与常量，不互相包含；上层驱动通过 `disp_reg.h` 提供的宏间接访问底层寄存器，实际 I/O 由 `disp_read_u32`/`disp_write_u32`/`disp_read_u8`/`disp_write_u8` 完成（来自 `display.h`）。
