- 每个硬件模块的寄存器定义独立存放在同名 `*_register.h` 文件中，并以 `Reg_<Block>_<Addr>` 联合体形式描述位域，同时提供 `Register_<Block>_Mmio_<N>_Start` 基址宏。
- 所有寄存器字段读写统一通过 `reg32_write_field_N` / `reg8_write_field_N` 及对应的 read 宏进行，禁止直接对联合体成员赋值，以保证读-改-写原子性。
- 按实例（CRTC/DP/DSC/SR/CR）的寄存器访问通过 `crtc_write_field`/`dp_write_field`/`dsc_write_field`/`sr_write_field`/`cr_write_field` 等封装宏完成，自动从 `pdd->reg_off.*` 表计算最终物理地址。
- 生成的头文件顶部固定包含 `Generated Time`、`Attention: This header file is generated by tool automatically, Do not modify it manually !!!` 以及版权声明块。
- 寄存器位域最大值统一通过 `((1u << N) - 1)` 形式的 `BitField_MaxValue` 宏表达，便于验证写入值的合法性。
