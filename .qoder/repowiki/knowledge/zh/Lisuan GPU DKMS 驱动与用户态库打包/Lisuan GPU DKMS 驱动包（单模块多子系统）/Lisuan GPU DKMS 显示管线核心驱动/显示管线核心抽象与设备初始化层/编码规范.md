- 所有对外导出函数均使用 `DISP_DLLEXPORTS` 修饰符声明，返回类型为 `DISP_STATUS`，错误码统一采用 `DISP_E*` 枚举值。
- 数据结构普遍采用 `typedef struct _xxx_t { ... } xxx_t, *pxxx_t;` 命名模式，并配合 `DISP_IN`/`DISP_OUT` 宏标注参数方向。
- 位域配置通过匿名 union 的 `.bits` 结构与整型 `.val` 字段并存，便于按位设置与整体赋值（如 `disp_device_init_t::flag`、`disp_plane_update_para_t::flag`）。
- 日志输出统一通过 `disp_print_ex`/`disp_print_pure_ex` 系列函数，结合 `DISP_PRINT_MASK_*` 位掩码进行模块级过滤，并在 `display.c` 中用宏简化为 `disp_print(level, log, ...)`。
- 所有平台相关操作（printf/malloc/IO 读写等）均通过 `disp_callback_t` 回调表间接调用，核心代码不直接包含 stdio 或内核 API。
- 常量与宏统一使用 `DISP_` 前缀，且大量使用 `#ifndef` 保护以兼容内核/EDK2 不同环境中的重复定义。
