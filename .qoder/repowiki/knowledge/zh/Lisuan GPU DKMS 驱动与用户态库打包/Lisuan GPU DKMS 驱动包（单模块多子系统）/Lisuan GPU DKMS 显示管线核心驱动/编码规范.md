- 所有对外 API 以 DISP_DLLEXPORTS 修饰并通过 display.c 集中导出，内部实现按 disp_xxx.c 拆分到对应子模块。
- 函数命名采用 disp_<module>_<action> 前缀（如 disp_crtc_set_mode、disp_encoder_dpms、disp_connector_sw_init），参数以 pdisp_* 指针形式传递。
- 错误码统一使用 -DISP_E* 负值返回（如 -DISP_ENOMEM、-DISP_EINVAL、-DISP_EPRIV_DEVICE_ID），成功返回 DISP_OK。
- 日志通过 disp_print_ex/DDM_* 级别输出，关键路径使用 disp_print_addition_file 将 trace 追加到文件。
- 硬件资源通过 disp_device_t 中的数组（disp_crtc[]、disp_encoder[]、disp_connector[]）+ index 索引访问，所有调用前检查 index < DISP_*_NUM。
- 寄存器访问统一通过 register/ 下定义的偏移表（reg_off.*）配合 8/32 位读写宏，禁止直接硬编码地址。
