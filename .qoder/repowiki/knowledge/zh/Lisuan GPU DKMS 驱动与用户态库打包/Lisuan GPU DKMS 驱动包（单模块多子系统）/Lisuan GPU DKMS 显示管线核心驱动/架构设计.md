本目录作为显示子系统的统一对外边界，由 display.c 提供所有 DISP_DLLEXPORTS 导出函数（display_device_init / display_crtc_set_mode / display_encoder_dpms / display_detect_connector / display_aux_transfer / display_backlight_* / display_psr_* 等），内部仅做参数校验与索引转发，实际逻辑委托给 disp_device.c 的 disp_device_sw_init/hw_init 编排器。
- 设备生命周期：display_device_init → disp_set_callback → disp_malloc(disp_device_t) → disp_device_sw_init（按顺序初始化 CRTC→Encoder→Connector→DSC）→ disp_device_hw_init（解锁寄存器→DHI→CRTC→Encoder→Codec）。
- 资源拓扑：disp_device.c 中 disp_sw_map_from_chip_define 将 chip define 映射为 reg_off[CR/SR/PIPE/PLL/DP/PPA/DSC/PWM] 等偏移表，并默认 4×DP，dvo_enable 时强制 pipe_a 为 DVO。
- 子模块协作：CRTC（disp_crtc）负责 Pipe/Plane/PLL/HDR；Encoder（disp_encoder）封装 HDMI/DP/DVO 及 PHY/DSC/FEC；Connector（disp_connector）实现 EDID/DisplayID/Mode/PWM/AUX；HDAudio（disp_codec）同步音频；Intr（disp_intr）分发 VSYNC/HPD；Register 提供统一的 8/32 位读写宏。
- 回调机制：上层通过 pdisp_callback 注入内存分配/打印/I2C/AUX/IRQ 等能力，使同一套代码可运行于 Linux 内核与 EDK2 GOP 环境。
- 错误与日志：全链路使用 disp_print_ex/DDM_* 级别输出，关键路径支持 disp_print_addition_file 把 trace 写入文件。
