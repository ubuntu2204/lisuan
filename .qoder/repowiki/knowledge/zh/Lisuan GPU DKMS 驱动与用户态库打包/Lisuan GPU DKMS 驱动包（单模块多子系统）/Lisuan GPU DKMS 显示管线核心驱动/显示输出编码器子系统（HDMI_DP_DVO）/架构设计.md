模块以 `disp_encoder.h` 中定义的 `disp_encoder_t` 结构体和 `disp_encoder_func` 函数指针表为核心抽象，通过 `DISP_ENCODER_TYPE`（HDMI/DP/DVO）在 `disp_encoder.c` 的 `disp_encoder_sw_init` 中按类型分派到具体实现：`disp_hdmi_encoder.c`、`disp_dp_encoder.c`、`disp_dvo_encoder.c`。每个具体编码器仅暴露 `*_sw_init` 入口，公共的 `hw_init/hw_deinit/dpms/mode_set/policy_config` 等调用均通过 `func` 虚表间接分发，形成清晰的“公共编排 + 各编码器独立实现”分层。

- DP 分支进一步拆分为 `disp_dp_encoder.c`（协议栈：link training、SDP/InfoFrame、PSR、FEC）与 `disp_dp_phy.c`（Cadence Torrent PHY 寄存器配置、swing/emphasis 调优），两者通过 `dp_phy_t` 结构体解耦。
- HDMI 分支集中在 `disp_hdmi_encoder.c`，提供完整的 CEA-861-G InfoFrame 打包器（AVI/SPD/AUDIO/DRM/VENDOR），并通过 `hdmi_infoframe_t` 联合体统一编解码接口。
- DSC 压缩由 `disp_dsc.c` 独立实现，以 `disp_dsc_t` + `disp_dsc_func` 形式挂载到 encoder 的 `pdsc` 指针上，支持 FEC 与动态带宽协商。
- 依赖方向单向向下：encoder → phy/dsc；上层通过 `disp_encoder.h` 暴露的统一 API 访问，不感知具体协议差异。
