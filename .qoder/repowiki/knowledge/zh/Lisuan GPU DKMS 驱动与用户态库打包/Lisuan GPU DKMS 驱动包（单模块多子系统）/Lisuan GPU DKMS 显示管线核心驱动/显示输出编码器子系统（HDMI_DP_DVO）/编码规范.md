- 所有公开结构体通过 `*_caps` / `*_state` / `*_policy` 三类命名分离能力、运行时状态与可配置策略，且策略结构体普遍采用 `union { struct { ...bits; } bits; disp_u32_t value; }` 形式同时支持位域与整型访问。
- 具体编码器实现仅导出 `*_sw_init` 初始化函数，其余生命周期操作（hw_init/hw_deinit/dpms/mode_set）通过 `disp_encoder_func` 函数指针表由公共层分派，避免直接调用具体实现。
- 错误码统一使用 `-DISP_E*` 负值枚举返回，成功返回 `DISP_OK`，并在入口处对空指针参数做防御性检查后返回 `-DISP_EINVAL`。
- 日志打印统一通过 `#define disp_print(level, log, ...) disp_print_ex(DISP_PRINT_MASK_ENCODER, level, log, ##__VA_ARGS__)` 宏包装，屏蔽不同打印通道的细节。
- PHY 寄存器地址全部以 `PMA_Reg_Addr_*` / `PHY_Reg_Addr_*` 宏集中定义，并按 lane 编号（Lane0/Lane1/Lane2/Lane3）成组排列，便于批量配置。
