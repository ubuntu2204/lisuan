- 每个模块以 `disp_<module>_sw_init` / `disp_<module>_hw_init` / `disp_<module>_hw_deinit` 三件套划分软件初始化与硬件生命周期，返回 `DISP_STATUS` 并检查空指针后早期返回 `-DISP_EINVAL`。
- 结构体定义采用 `_t` 后缀（如 `disp_crtc_t`、`disp_pipe_t`、`disp_plane_t`），并配套 `pdisp_*_t` 指针别名，字段命名使用小写下划线且带明确前缀。
- 属性访问通过 `crtc_get_property_*` / `crtc_set_property_*` 内联函数对 `disp_crtc_property_t` 进行 get/set，避免直接访问结构体成员。
- 日志输出统一通过 `disp_print(DDM_WARNING, ...)` 宏，而非直接调用 printf 或 printk。
- 寄存器访问通过 `Reg_*_MMIO_*` 联合体结构体配合 `disp_read_u32/disp_write_u8` 完成，先读再改位域后写回，保证原子性。
