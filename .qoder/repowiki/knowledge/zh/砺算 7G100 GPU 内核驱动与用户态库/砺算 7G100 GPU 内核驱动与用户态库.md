### 身份与角色
- 砺算（Lisuan Technology，PCI ID 4c54）GPU 的 Linux DRM 内核驱动，模块名为 `gf`（`gf.ko`），安装到 `/kernel/drivers/gmu/drm/gf`。
- 配套用户态库包 `lisuangpu-lib`，由官方 `.deb` 提供。

### 集成要点
- DKMS 配置在 `dkms.conf`，构建命令传入 `KERNELVER=$kernelver`。
- Makefile 原用 `KERNEL_VERSION := $(shell uname -r)` 决定目标内核，与 DKMS 传入的 `KERNELVER` 不一致，导致编译产物 vermagic 错配；修复后改为 `$(if $(KERNELVER),$(KERNELVER),$(shell uname -r))`。
- 唯一闭源二进制为 `objs/x86_64/lisuan_proprietary.o.hex`（经 xxd 还原为 `ar` 归档，内含 `gf_hw_misc.o`、`gf_hw_cmds.o`），仅依赖稳定符号 `__fentry__`、`sscanf`，其余全部来自可重编译的开源胶水层。
- 支持的 GPU：`0x4c54:0x5006`（G100/7G100 家族），加载后绑定到对应 PCI 设备。

### 使用模式
- 通过 `_work/fix-lisuan-gpu.sh` 执行：对 `/usr/src` 中的 Makefile 打持久补丁 → `dkms remove/build/install` → `depmod` + `modprobe gf` → 验证 `/dev/dri/card*` 节点生成。
- Secure Boot 需关闭或模块签名，否则 `modprobe` 会被拒绝。

### 注意事项
- 内核升级后必须重新 DKMS 构建，确保 `KERNELVER` 指向新内核头文件。
- 验证方法：`modinfo gf.ko | grep vermagic` 应与运行内核一致；`lspci -nnk -s 03:00.0` 应显示 `Kernel driver in use: gf`。
